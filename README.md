# ahnboat.xyz 홈페이지 운영 매뉴얼

박사 · 조수 하루 · 주판봇 · 초파리 연구원이 안내하는 [ahnboat.xyz](https://ahnboat.xyz/) 운영 매뉴얼입니다.

**매뉴얼 보기:** https://adminmrobo.github.io/ahnboat_homepage_manual/ (관리자 비밀번호가 필요합니다)

내용은 `manual.enc`에 AES-256-GCM으로 잠겨 있고, 브라우저에서 비밀번호를 넣으면 풀립니다. 잠기기 전 원문과 잠금 도구는 저장소에 올리지 않습니다.

| 장 | 내용 |
|---|---|
| 1~3 | 안내하는 식구들, 홈페이지 한눈에 보기, 무엇이 언제 바뀌나 |
| 4~5 | 새 콘텐츠 올리기, 공지·일정·포트폴리오 |
| 6~8 | 검색과 3D 지도, 7개 언어 번역, 방문 집계와 오늘의 레포트 |
| 9~12 | 워드프레스에 붙여 넣기, 꼭 지킬 것, 고장 났을 때, 파일 지도 |

홈페이지 화면과 데이터는 [ahnboat_lab_cover_status](https://github.com/adminmrobo/ahnboat_lab_cover_status) 저장소에 있습니다.
